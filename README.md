# Implementasi Input, Output, dan Operator Python

Repository ini berisi kumpulan *source code* dan latihan praktikum pemrograman Python yang berfokus pada pemrosesan teks, manipulasi *string*, operasi input/output, serta penggunaan berbagai jenis operator.

## 📌 Topik Pembahasan

- **String Manipulation:** Penggunaan metode bawaan seperti `.startswith()`, `.endswith()`, `.rjust()`, `.ljust()`, dan `.center()`.
- **String Formatting & Escape Characters:** Implementasi tanda petik tunggal/ganda, karakter *escape* (`\`), *newline* (`\n`), serta *multiline string* (`"""..."""`).
- **Input & Output:** Menerima *input* dari pengguna dan menampilkan *output* yang terformat ke terminal.
- **Operasi Aritmatika & Logika:** Penggunaan operator dasar untuk memproses data.

## 📁 Struktur File

Setiap latihan disimpan dalam bentuk script Python (`.py`):
- `test1.py` hingga `test8.py`: Program latihan praktikum manipulasi string dan operator.
